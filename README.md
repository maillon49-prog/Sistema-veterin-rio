# Sistema Veterinário

Sistema web desenvolvido para praticar JavaScript, manipulação do DOM, validações, navegação entre telas e persistência de dados no navegador.

O projeto simula funções básicas de um sistema veterinário, com cadastro e login de usuários e gerenciamento de pets.

## Funcionalidades

- Cadastro de usuários
- Login com validação de usuário e senha
- Cadastro de pets
- Consulta de pets cadastrados
- Edição de dados de pets
- Exclusão de pets
- Validação de campos obrigatórios
- Bloqueio de cadastros duplicados
- Persistência de usuários e pets com `localStorage`
- Navegação entre diferentes telas do sistema

## Dados armazenados para cada pet

- Nome
- Espécie
- Raça
- Idade
- Dono

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage

## Como executar

Clone o repositório ou baixe os arquivos e abra:

```text
index.html
```

no navegador.

Como os dados são armazenados no `localStorage`, não é necessário configurar banco de dados ou servidor para utilizar esta versão.

## Objetivo do projeto

O sistema foi criado como projeto de aprendizado para praticar CRUD no front-end, autenticação simples, manipulação de dados e organização de uma aplicação com múltiplas telas.

O projeto ainda pode receber novas funcionalidades e melhorias.
